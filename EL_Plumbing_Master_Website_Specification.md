# EL Plumbing — Master Website Specification

## 1. Project Overview

**Project:** EL Plumbing Website  
**Current Phase:** Initial one-page visual prototype  
**Business:** EL Plumbing  
**Business Type:** Plumbing, sanitary ware, building materials and related products supplier/retailer

EL Plumbing is a physical business that supplies plumbing materials, sanitary products, bathroom products, pumps, fittings, tools/hardware and other building-related materials.

The first objective is NOT to build a full e-commerce platform. The objective is to create a polished, professional website concept that demonstrates how EL Plumbing can present itself online and generate enquiries from customers, contractors, builders and businesses.

The prototype should feel like a real, credible business website rather than a generic AI-generated template.

---

## 2. Primary Website Objective

The website should follow this basic conversion journey:

**Show the products → Establish trust → Explain the business → Generate enquiries**

Visitors should quickly understand:

- What EL Plumbing does
- What types of products it supplies
- That it is a real physical business
- That it serves both individual customers and professional/business customers
- How to request information, availability or a quotation
- How to contact the business directly

The primary conversion action should be **Request a Quote / Enquire**, not online checkout.

---

## 3. Target Audience

### Primary
- Contractors
- Builders
- Construction companies
- Plumbing professionals
- Businesses purchasing building/plumbing materials
- Property/project managers

### Secondary
- Homeowners
- Individuals renovating or building
- Customers looking for bathroom and sanitary products
- General walk-in customers

The website should therefore feel professional enough for business customers while remaining approachable for individual customers.

---

## 4. Business Positioning

Do NOT position EL Plumbing as only a plumbing-services company.

Based on the supplied business photographs, EL Plumbing should be presented as a:

> **Plumbing, Sanitary & Building Materials Supplier**

Possible supporting positioning:

> Plumbing, sanitary ware, bathroom products, pumps, fittings and building materials for customers, contractors and businesses.

Do not invent claims such as:
- Number of years in business
- Number of customers
- Certifications
- Awards
- Brand partnerships
- Delivery capabilities
- Geographic coverage
- Guaranteed availability
- Customer testimonials
- Project counts

If information has not been provided, use editable placeholders or omit it.

It does NOT need:

- Full e-commerce

- Inventory management

Secondary CTA:

# 18. Typography

Use a modern, professional sans-serif typeface.

Recommended direction:

- Bold/semibold display typography for major headings
- Clean regular/medium typography for body content
- Strong hierarchy
- Generous line-height
- Large hero typography
- Avoid decorative fonts

Potential font pairing:

- Space Grotesk / Inter
- Manrope / Inter
- Plus Jakarta Sans

Choose one coherent system rather than mixing many fonts.

Typography should communicate a professional supplier, not a luxury fashion brand.

# 20. Animation & Motion System

Animations SHOULD be used, but restraint is critical.

## Use

### Scroll reveal
- Fade + small vertical movement
- 300–700ms
- Stagger related items subtly

### Image hover
- Slight scale, approximately 1.02–1.05
- Smooth transition

### Product/category interaction
- Crossfade/slide image transition
- Smooth and fast

### Buttons
- Subtle background/colour transition
- Slight movement where appropriate

### Navbar
- Smooth background/shadow transformation after scrolling

### Gallery
- Subtle image zoom on hover
- Lightbox transition if implemented

## Avoid

- Excessive parallax
- Large text flying from every direction
- Cursor-following effects
- Heavy 3D effects
- Constant floating elements
- Excessive blur/glassmorphism
- Long loading animations
- Animating every component independently

Motion should communicate hierarchy and interaction, not show off technology.

---

# 21. UX Principles

The website must prioritize:

### Clarity
Visitors should understand the business within seconds.

### Trust
Use authentic business photography and real information.

### Contactability
WhatsApp/call/enquiry should always be easy to access.

### Product discovery
Visitors should quickly understand the available product categories.

### Professional credibility
The visual quality should be significantly better than a typical local supplier website.

### Mobile first
A large percentage of users may arrive through WhatsApp/social media/mobile search.

---

# 22. Mobile Requirements

The mobile version is not a compressed desktop site.

It must have:

- Clean hamburger navigation
- Large readable headings
- Touch-friendly buttons
- Product cards optimized for narrow screens
- Horizontal category interactions only when genuinely useful
- Proper image cropping
- Sticky or floating enquiry/contact action where appropriate
- Fast loading
- No horizontal overflow

---

# 23. Accessibility

Include:

- Semantic HTML
- Proper heading hierarchy
- Accessible buttons
- Keyboard navigation
- Visible focus states
- Alt text for meaningful images
- Adequate colour contrast
- Reduced-motion support

If a user has `prefers-reduced-motion`, reduce or disable non-essential animation.

---

# 24. Performance

Prioritize:

- Optimized images
- Lazy loading below-the-fold imagery
- Responsive image sizes
- Minimal unnecessary JavaScript
- Avoiding oversized video backgrounds
- Smooth performance on mid-range mobile devices

Do not sacrifice usability for visual effects.

---

# 25. Technical Direction

The implementation should be modern and maintainable.

Preferred:

- React
- TypeScript
- Vite or an equivalent modern frontend setup
- Tailwind CSS or a clean CSS architecture
- Reusable components
- Responsive layout
- Component-driven structure

Keep content/data separated from presentation wherever practical.

Example conceptual structure:

```text
src/
  components/
  sections/
  data/
  assets/
  styles/
```

Product categories, product data and contact information should be easy to replace later.

# 30. Core Design Principle

The website should communicate:

> **"This is a real business with real products, and I can contact them when I need materials."**

It should NOT communicate:

> "This is an AI-generated website with lots of animations."

The design quality should come from:

- Strong art direction
- Typography
- Layout
- Photography
- Spacing
- Product presentation
- Interaction design
- Clear messaging

not excessive visual effects.

---

# 31. Initial Success Criteria

The prototype is successful if a first-time visitor can answer these questions within approximately 5–10 seconds:

1. What is EL Plumbing?
2. What do they sell?
3. Can they supply businesses/contractors?
4. Do they look like a real established business?
5. How can I enquire?

The prototype should also be visually strong enough that the business owner can imagine using it as the foundation of the real website.
